Firmware Flasher

Flash your device straight from this page. No software to install.

Your browser can't do this. Web Serial only works in Chrome or Edge on a computer (not phone/tablet, not Safari or Firefox). Open this page in Chrome or Edge and try again.

Select the firmware file

Choose the .bin file you were sent, and tell it what kind of file it is.

2

Connect your board

Plug the device into a USB port, then click connect and pick it from the list.

Advanced options

OTA mode writes the app to 0x20000 and resets the boot slot selector at 0xf000 so it boots the new app — the bootloader, partition table, and WiFi settings aren't touched.

3

Flash it

This takes a minute or two. Don't unplug the device or close this tab while it runs.
